# design-system/logos

Own-IP marks only, staged here for retrieval by chat sessions and public tools that
can't reach the private repos or vault where these packages actually live. This is a
pointer/mirror location, not the canonical source — see `samcos/knowledge/design-system/index.md`
for the full package index and where each source of truth actually lives.

## What's here

- `samcos-shieldmark.svg` — SAM COS ShieldMark ("Fc" mark). Outlined paths.
- `orion-mark-primary.svg` — ORiON ring-and-belt mark. Outlined paths.
- `metis-mark-primary.svg` — Métis convergence mark. Outlined paths.
- `jr-rhodonea-mark-{light,dark}.png` — Jim personal rhodonea mark. Raster, no embedded font.

## What's deliberately absent

- **No licensed fonts.** Sons Condensed (Klim Type Foundry) is licensed and is never
  staged to this public repo, in any form — no `.ttf`/`.otf`, and no SVG wordmark that
  renders it as live `<text>`.
- **No GE Vernova corporate assets.** Corporate logos/tokens/fonts stay in their vault
  zip only; this repo carries only the four products' own marks, not the parent brand.
- **No wordmarks.** Every wordmark variant across these packages (Métis in particular)
  currently renders as live `<text>` in Sons Condensed rather than outlined paths —
  staging one here would leak the licensed typeface. Only the non-wordmark marks are
  staged. When a wordmark is outlined to paths, it can be added as its own task.
